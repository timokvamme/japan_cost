# inbox/

Instructions and files pushed by the **app-side Claude** for the **Shadow PC Claude**
to act on.

- Name files `YYYY-MM-DD-short-topic.md` (or drop whole files/folders with a matching
  `.md` note explaining what to do with them).
- Shadow PC Claude: after acting on an item, `git mv` it into `inbox/done/` and record
  the outcome in `outbox/`.
